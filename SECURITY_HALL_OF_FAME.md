# Security Hall of Fame

We are deeply grateful to the security researchers who have responsibly
disclosed vulnerabilities in NexusDL. Responsible disclosure keeps our users
safe and our project healthy.

**Thank you.** 🙏

---

## How to be listed here

If you have reported a security vulnerability and we have confirmed and fixed
it, you will be listed here **unless you prefer to remain anonymous**.

Credit includes:

- Your name or handle (as you prefer to be credited)
- A link to your website, GitHub, or social media (optional)
- The vulnerability type (per our classification)
- The date of disclosure
- A link to the GitHub Security Advisory (if public)

To report a vulnerability, please see [SECURITY.md](SECURITY.md).

## Recognition levels

We do not offer monetary rewards (see [SECURITY.md](SECURITY.md#bug-bounty)),
but we offer the following recognition levels:

| Level | Criteria | Recognition |
|---|---|---|
| 🥇 **Gold** | Critical vulnerability with a working PoC, or a vulnerability that prevented a real-world attack | Permanent listing + public thank-you + optional blog post feature |
| 🥈 **Silver** | High-severity vulnerability | Permanent listing + public thank-you |
| 🥉 **Bronze** | Medium or low-severity vulnerability | Permanent listing |
| ⭐ **Honorable mention** | Non-exploitable finding or a well-documented false positive | Listing on request |

---

## Disclosure timeline reference

For each entry, the "Date" column refers to the date of the **first
acknowledgment** by the maintainers, not the date of the fix. This is the
date that will remain in this file forever.

If a vulnerability was discovered earlier but reported later, the date of
**report** is used.

## Special thanks

Beyond individual researchers, we thank the following organizations and
initiatives that help keep NexusDL and its dependencies secure:

- [**GitHub Security Lab**](https://securitylab.github.com/) — for CodeQL,
  secret scanning, and Security Advisories
- [**OSV.dev**](https://osv.dev/) — open-source vulnerability database
- [**PyPA**](https://www.pypa.io/) — for `pip-audit` and secure Python
  packaging standards
- [**OpenSSF**](https://openssf.org/) — for the Scorecard and best practices
- [**CVE Program**](https://www.cve.org/) — for vulnerability identifiers
- [**FIRST**](https://www.first.org/) — for CVSS scoring
- [**MITRE**](https://www.mitre.org/) — for CWE classification
