# NexusDL — User-Agent pool
#
# File: src/nexusdl/data/user_agents.txt
#
# This file contains a pool of REAL, MODERN User-Agents used by
# `core/session/user_agents.py` for rotation (anti-bot detection).
#
# Format:
#   - One User-Agent per line
#   - Lines starting with `#` are comments (ignored)
#   - Empty lines are ignored
#   - No line continuation
#
# Rotation:
#   - `UserAgentPool.random()` → random UA
#   - `UserAgentPool.round_robin()` → sequential UA
#
# ⚠️  Do NOT include:
#   - Bots (Googlebot, Bingbot, curl, wget, python-requests, etc.)
#   - Old browsers (IE11, Chrome < 100, Firefox < 100)
#   - Headless markers (HeadlessChrome)
#   - Application-specific UAs (NexusDL/0.1.0)
#   - Accents or non-ASCII characters
#
# ⚠️  Keep this list MODERN (updated ~every 6 months).
#     The sites used by NexusDL may ban outdated UAs.
# ════════════════════════════════════════════════════════════════════
